About

From classroom to codebase.

I run an institution and write the software that runs it — that loop is where most of what I know comes from.

I'm a Computer Science undergraduate from Shikarpur, Sindh, currently in my 7th semester at Sukkur IBA University. Alongside my degree, I founded and independently run Jeewan Tuition Classes, teaching Classes 1–12 across eight subjects.

Running JTC on my own meant I needed software more than I needed extra hands — so I built it. A Flask-based student management system now handles attendance, fees, report cards, and WhatsApp reminders for 27 students. That same instinct — spot a repetitive problem, build a tool — carried into my coursework, where I've shipped an NLP chatbot and a student performance predictor, both live and deployed.

I care about software that's actually used, not just submitted. Every project below is running somewhere right now.
