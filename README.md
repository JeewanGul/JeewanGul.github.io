# 🚀 Jeewan Gul — Personal Portfolio

> **Live Site:** [jeewangul.github.io](https://jeewangul.github.io)

A fully animated, single-page personal portfolio website built from scratch with vanilla HTML, CSS, and JavaScript. No frameworks. No build tools. Just open `index.html` and it works.

I'm a Computer Science undergraduate at **Sukkur IBA University** (CGPA 3.41/4.0), full-stack developer, and founder of **Jeewan Tuition Classes** — a tutoring institution I built and scaled by writing all the software to run it myself.

---

## ✨ Features

- **Georgia serif typography** throughout
- **Particle network** canvas animation in the hero
- **Animated aurora blobs** floating in the background across the whole page
- **Custom cursor** — dot + lagging ring that grows on hover
- **Scroll progress bar** at the top
- **Staggered scroll reveals** — every section fades/slides in as you scroll
- **Line-by-line headline animation** with animated gradient text
- **Scan line + breathing glow** on the profile photo
- **3D tilt** on hover for cards and photo
- **Magnetic buttons** that pull toward the cursor
- **Animated counters** (CGPA, students, projects)
- **Skill chips** that pop in one-by-one
- **Horizontal marquee** tech stack ticker
- **Animated underline draw** on section headings
- **JTC screenshot slider** — 3 real screenshots with auto-advance, dots, arrows & swipe
- **Rotating social icons** on hover
- **Contact form** that opens a pre-filled email draft
- **Download CV** button (serves the actual PDF)
- Fully **mobile responsive** with hamburger nav
